# Rules for agents: hosting, the built site, CI and deploy, and live verification

These rows belong to the rules table in [AGENTS.md](../../AGENTS.md) and follow the same contract: every row names the check that fails when it is broken, and `npm run check:agents-md` checks that each named file, script and journey exists in this file too.

| Rule | Enforced by | Command |
| --- | --- | --- |
| `/`, `/index.html` and `/sw.js` get no-cache; the service worker precache covers every file the page loads; manifest icons exist; the manifest has no `orientation` lock (absent, `any` or `natural`; docs/architecture.md, Hosting); `robots.txt` exists in `dist/` as plain robots rules (a `User-agent:` line, no HTML) and `_headers` gives it no other Content-Type; the manifest `theme_color` and `background_color` and the built CSS's light `--paper` equal the light `<meta name="theme-color">` in `index.html`, which owns the color (no exception) | `scripts/check-dist.mjs`, `scripts/check-dist.test.mjs` | `npm run check:dist` |
